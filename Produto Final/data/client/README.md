# 📁 Dados do Cliente Aion Classic (Templates, Npcs, Skills, Items)

Esta pasta (`data/client/`) armazena os arquivos de dados extraídos do cliente do Aion Classic (como XMLs de templates, strings, NPCs, skills, itens, missões e mapas).

---

## 📥 Como Obter os Arquivos

Você tem duas opções para popular esta pasta:

### Opção 1: Download Direto dos Arquivos Prontos (Recomendado)
Faça o download do pacote de dados completo já extraído e pronto para uso através do Google Drive:
👉 **[Download dos Arquivos do Cliente no Google Drive](https://drive.google.com/drive/folders/1C-2M1opsREZ7DsQmUJS6fUpRTCF4A9oj?usp=sharing)**

Após baixar, basta extrair todo o conteúdo diretamente dentro desta pasta `data/client/`.

---

### Opção 2: Extração Manual dos Arquivos `.pak` do Cliente
Caso já possua o cliente do Aion Classic instalado:
1. Acesse a pasta `Data/` do seu cliente do jogo (onde estão os arquivos `.pak`).
2. Extraia todos os arquivos `.pak` (utilizando ferramentas como QuickBMS ou Aion Pak Extractor).
3. Copie as pastas e arquivos extraídos diretamente para dentro deste diretório (`data/client/`).

---

> ℹ️ **Nota**: Os arquivos brutos de dados não são versionados diretamente no Git devido ao tamanho (>1GB), sendo necessário seguir uma das opções acima para a execução completa com todos os recursos do mundo e NPCs.
